Passcodes

Each player sets their own passcode the first time they open the import page. It is what stops anyone else editing their stays. Reset one only when somebody has forgotten theirs. The next person to open that name gets to set a new one.

Recent deck writes

Every time somebody sends their stays in. A passcode is two tiles on purpose, so this is how you notice if one goes walkabout. A rewrite only ever touches that person's own stays, and the Worker keeps the previous version.
