# Name candidates

Three panels, fifteen names each. Working name was **StayTap**, which turns out
to be taken ([staytap.app](https://www.staytap.app/) is a live Airbnb host
welcome-book product) and reads as a MapTap sibling rather than its own thing.

---

## Panel 1 — linguist (brand naming, phonaesthetics, morphology)

| Name | Rationale |
|---|---|
| **Guestimate** | Haplological blend of GUEST + ESTIMATE sharing the /es/ nucleus; names both halves of the game. Autocorrect fights the single-S spelling. |
| **Wanderwho** | In connected speech a near-homophone of "wonder who" — a pun you hear before you parse it. |
| **Whodunstay** | Genre-frame substitution on *whodunnit*; the detective schema transfers wholesale. Final stress lands punchy. |
| **Stayku** | *Stay* + the *-ku* of haiku: reads as "very small daily form" without borrowing *-dle*. Spelling ambiguous aloud. |
| **Casawho** | *Casa* is legible across Romance, English and most of the travel world; ends on a rising /uː/, shaped like a question. |
| **Kipdrop** | British *kip* (a sleep, a place to sleep) + the pin gesture. Four stops in six phonemes — maximally crisp. |
| **Bunkwhere** | *Bunk* carries both "bed" and "nonsense", licensing the bluffing when friends argue. |
| **Whosepad** | Possessive does the social work, *pad* the lodging work, in two syllables. People will type it with a space. |
| **Kiptap** | Deliberate family resemblance to MapTap via the shared *-tap* head. |
| **Dwelt** | A preterite: the past tense itself encodes that these stays already happened. /dw-/ is a rare, distinctive onset. |
| **Doorcode** | The keypad is the universal arrival ritual. Sits closer to host-tool naming than game naming. |
| **Whoslept** | Maximum semantic transparency in two syllables; clean /pt/ full stop. |
| **Abodle** | *Abode* + *-dle*. Declares subject and genre in one word — but *-dle* is a tired morpheme. |
| **Nightly** | Double duty: the trade term for a rental rate *and* the adverb of cadence. |
| **Lockbox** | The physical object doubles as the puzzle metaphor. Most generic of the set. |

## Panel 2 — NYT Games designer

| Name | Rationale |
|---|---|
| **Sleepover** | Says "friends, someone's house, one night" with zero explanation. "Did you do today's Sleepover?" is a sentence people type. |
| **Guestbook** | The name *is* the mechanic — a book of who stayed where. Sets beautifully in serif; "Guestbook 142" reads like a ledger entry. |
| **Vacancy** | Neon motel-sign wordmark, faintly noir. Frames the game as a hole to fill rather than a quiz to pass. |
| **Nightstand** | Names the game's texture, not its rules — every listing photo has one. The *-stand* gives the wordmark a base. |
| **Latchkey** | Two hard consonants and a little melancholy. Means access without sounding like access control. |
| **Stay Put** | The only pun worth shipping because you never have to notice it: a stay, put on a map. |
| **Slept Here** | Borrowed plaque language that already fuses a person to a place — precisely the two answers. |
| **Turndown** | Hospitality vocabulary with a sly second meaning for a rejected guess. Never congratulates the player. |
| **Lockbox** | Honest metaphor — you're trying codes until it opens — without a word about maps or guessing. |
| **Postcard** | The share grid *is* a postcard. Risk: promises a prettier game than a pin-drop delivers. |
| **Housewarming** | Warmest word here, implies the group is invited. Four syllables sag above a puzzle number. |
| **Threadcount** | Names the tone — the absurd specificity of the amenity list — which ages better than describing the mechanic. |
| **Receipts** | Pure group-chat vernacular and literally what the data is. Plural above a number is slightly awkward. |
| **Kip** | Best pure wordmark at three letters. Coin flip whether half your friends know it means a sleep. |
| **Bunk** | Four letters, no ascender problems; the second meaning quietly forgives a bad guess. Faint dorm-room cheapness. |

## Panel 3 — daily-games obsessive (the player)

| Name | Rationale |
|---|---|
| **Guesthouse** | The pun is right there and never needs explaining. The only one that sounds like it could already be an NYT property. |
| **Digs** | One syllable, fun to say; "nice digs" is exactly the tone of judging your friend's 29-inch TV. Maybe too forgettable. |
| **Lockbox** | Sounds like a thriller, means nothing until you've played, then means everything. Slight crypto-wallet risk. |
| **Whodunstay** | Genuinely funny the first time and tells you the whole game — but it's a pun you must say aloud, and it'd tire by day 40. |
| **Vacancy** | Flickering motel sign, faintly ominous, cool as hell. Suggests emptiness rather than guessing. |
| **Sleeps Four** | Steals the voice of the listing copy itself, which is the actual joke of the game. Awkward as a verb. |
| **Late Checkout** | Fits the slow morning-coffee routine. Doesn't sound like homework at all. |
| **House Rules** | Confident and instantly Airbnb-flavoured, but reads like a trivia party game, not a map game. |
| **Bunk** | Punchy, slightly rude, double meaning that fits accusing your friends of things. Best pure *sound* on the list. |
| **Roost** | Warm and cozy, nobody else using it. Borderline too precious — like a houseplant tracker. |
| **Cleaning Fee** | The funniest name here and the most honest about what Airbnb is. But it's a bit, and bits age badly. |
| **Slept** | Past-tense one-worder in the exact mould of Framed — either good camouflage or an admission you're a clone. |
| **Superhost** | Smug. Makes the *winner* the brand, which is the opposite of a private friend thing. |
| **Stay Put** | Cute, gentle, ironic for a travel game. A touch quiet for a game where you're publicly wrong by 4,000 km. |
| **Trundle** | A real bed word, fun in the mouth — but *-dle* puts you in a bin with hundreds of dead Wordle clones. Don't. |

## Conflicts found (all three panels searched)

**Disqualified — an existing daily game in an adjacent genre**

- **Whereabouts** — [whereabouts.earth/daily](https://whereabouts.earth/daily/) is a live daily world-map pin game. Direct competitor.
- **Pindrop / Keydrop** — [playpindrop.app](https://playpindrop.app/) is already a daily geography game; PINDROP is also a registered security trademark. Avoid the whole *-drop* family except *Kipdrop*.
- **Digs** — "Daily Digs" already exists inside [PropQwiz](https://apps.apple.com/us/app/propqwiz/id6738093427), a daily property price-guessing game.
- **Alibi** — [a running daily deduction puzzle](https://knotwise.games/games/alibi).
- **Guess The House** — [an existing daily home-price photo game](https://dlegames.org/game/guess-the-house); adjacent enough to matter.

**Trademark / crowding cautions**

- **Guestbook** — [The Guestbook](https://tracxn.com/d/companies/the-guestbook/__2wvtwilz-WqnzkDpcTRQS-7N6Ke2tO31zQN7kHKGi98) is a funded hotel-booking rewards startup. Adjacent industry.
- **Guestimate** — crowded: an App Store game, getguesstimate.com, and a GmbH.
- **Threadcount** — a [registered apparel trademark](https://trademarks.justia.com/owners/threadcount-llc-3631678).
- **Roost** — [Roost Social](https://apps.apple.com/us/app/roost-social/id6746680855), a viral messaging app.
- **Nightly** — collides with browser release channels. Fine for a game, bad for search.
- **Guess Who** — live Hasbro mark; the pun is too close.
- **Superhost** — an Airbnb program name. Don't.

**Clean, nothing meaningful found**

Whodunstay, Stayku, Casawho, Kipdrop, Bunkwhere, Whosepad, Kiptap, Whoslept,
Abodle, Sleepover, Vacancy, Turndown, Slept Here, Housewarming, Kip, Bunk,
Receipts, Postcard, Latchkey, Nightstand, Lockbox, Stay Put, Guesthouse,
Sleeps Four, Late Checkout, House Rules, Cleaning Fee, Slept.

**General**

- *-dle* and *-guessr* are exhausted — aggregators list 400–700 of them. Anything
  like "Stayle" or "Stayguessr" reads as the thirtieth clone on sight.
- Anything containing "bnb" borrows a trademark not worth explaining.
- *-tap* will date the way *-dle* did.
